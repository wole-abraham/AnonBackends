# Anon Platform Backend

This is the backend for the anonymous posting platform, built with FastAPI and Supabase.

## Setup

1.  **Environment Variables**:
    -   Copy `.env.example` to `.env`.
    -   Fill in `SUPABASE_URL` and `SUPABASE_KEY` from your Supabase project settings.

2.  **Supabase Database Setup**:
    -   Go to your Supabase project dashboard -> SQL Editor unless you prefer the Table Editor.
    -   Run the following SQL to create the `posts` table:

    ```sql
    create table public.posts (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      title text,
      content text not null,
      is_anonymous boolean default true,
      deletion_password text not null
    );
    ```

    -   **Comments Table**:
    
    ```sql
    create table public.comments (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      content text not null,
      author_name text default 'Anonymous',
      post_id bigint references public.posts(id) on delete cascade not null
    );
    ```

    -   Enable Row Level Security (RLS) if you want to restrict access, or leave it disabled for public access (checking the "Enable Row Level Security (RLS)" box). For a truly public anonymous board where anyone can post, you might need to add a policy or disable RLS for now (be careful with disabling RLS in production).
    
    Example Policy for public insert:
    - strict: true
    - check: true
    - definition: true

3.  **Run the Server**:
    -   Make sure you are in the `Anon` directory (where `requirements.txt` is).
    -   Run: `uvicorn app.main:app --reload`

4.  **API Documentation**:
    -   Once running, go to `http://127.0.0.1:8000/docs` to see the interactive API documentation.
